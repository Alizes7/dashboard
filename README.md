# SuperABC - Transição Contábil 2026

Sistema completo de Dashboard Online para gerenciamento da Transição Contábil do Grupo Super ABC.
Desenvolvido pela A2Consultores.

## 🚀 Tecnologias

- HTML5 + Tailwind CSS (via variáveis CSS)
- Vanilla JavaScript (ES6+)
- LocalStorage (persistência offline)
- Design Responsivo
- Dark Mode

## 📁 Estrutura

```
superabc-transicao-contabil/
├── index.html              # Página principal
├── assets/
│   ├── css/
│   │   └── style.css       # Estilos completos
│   └── js/
│       ├── data.js         # Dados iniciais
│       └── app.js          # Lógica do sistema
└── README.md
```

- ✅ Dashboard com KPIs e gráficos
- ✅ Cronograma interativo com filtros

## 🚀 Como Hospedar

### Opção 1: Vercel (Recomendado)

1. Instale o Vercel CLI: `npm i -g vercel`
2. No terminal, navegue até a pasta do projeto
3. Execute: `vercel`
4. Siga as instruções

### Opção 2: Netlify

1. Acesse [netlify.com](https://netlify.com)
2. Arraste a pasta do projeto para a área de deploy
3. Pronto!

### Opção 3: GitHub Pages

1. Crie um repositório no GitHub
2. Faça push dos arquivos
3. Ative o GitHub Pages nas configurações

### Opção 4: Servidor Local

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .

# PHP
php -S localhost:8000
```

Acesse: http://localhost:8000
